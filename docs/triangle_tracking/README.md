## 跟踪无响应诊断版本

用户确认屏幕稳定标注“三角形”。已补充实际 PWM 周期、异步像素时钟的完整链路仿真，
验证左侧、右侧、中心、无新帧及暂停均通过；不能据此认定板上输入及电机模式正确。
新增诊断只观测状态，不改变增益、模式、方向和 PWM 命令。
本版 LED 改为以下含义，不能继续按原 DDR 状态解释：

| 逻辑编号 | 亮表示 |
|---|---|
| LED0 | 目标选择结果经过 CDC 到达电机时钟域 |
| LED1 | 控制器允许跟踪：目标、确认、使能、超时条件均满足 |
| LED2 | 跟踪处于暂停状态 |
| LED3 | 最近 250ms 收到过视觉帧样本（即使没目标也亮） |
| LED4 | 最近 250ms PWM 脉宽命令发生变化；不代表电机实际收到波形 |
| LED5 | 位置命令到达脉宽限位 |

方向沿用反转设置。观察时让三角形明显偏左或偏右，并保持 2 秒。
LED0灭但屏幕有标签：目标选择/过滤/CDC问题，结合LED3区分样本缺失。
LED2亮：K2暂停输入阻止控制。LED0、3亮但1灭：控制资格未满足。
LED1、4亮但电机不动：命令已产生，需进一步测实际 PWM 波形及确认电机模式。
LED5亮时，该方向受脉宽限位限制；将目标移到相反侧观察能否退出。
LED 按逻辑编号，以原理图为准，不假定实物从左到右的排列。

## K1循环与K2暂停细节

K1默认从12开始，每次稳定按下加4，达到32后再按回4；按住不连续调节。
串口T仍可写4～32中的任意整数，K1从当前值加4，跨越上限先钳制32，下次回4。
K1沿用20ms消抖。K2未接入阈值控制器，按住K2不会减阈值。

K2为低有效，经过两级同步及按下/松开各20ms消抖。每次稳定按下切换暂停/恢复，长按只切换一次；上电默认允许跟踪。
位置模式暂停后保持最后位置命令，50Hz PWM继续输出。暂停不停止图像采集、识别、显示，K1及串口T仍能调节阈值。
恢复会切换样本代号，丢弃暂停前及暂停期间尚在跨时钟通道中的样本；像素域看到恢复代号后，从下一次帧同步启动的目标选择开始发送。
恢复必须收到两次新的有效三角形目标选择样本才允许控制；无目标会清零确认计数，样本超时300ms也会失效。
这里“新样本”指恢复之后的新帧目标选择结果，不要求目标换成另一物体，也不额外等待几何识别器的三次确认重新执行。
速度模式暂停/失效输出1500us中立命令，位置模式保持当前位置命令。

画面左上角常驻两行状态，按帧锁存，所有显示模式均可见：

| 显示 | 含义 |
|---|---|
| THR:12 | 当前生效高阈值，低阈值为其一半；默认12 |
| PAUSED（橙） | K2暂停 |
| WAIT（黄） | 等待新样本、两次目标确认，或无目标/超时 |
| TRACK（青） | 正在允许跟踪 |
| CENTER（绿） | 目标进入水平居中死区 |
| LIMIT（红） | 跟踪命令到达脉宽限位 |

暂停显示优先，其次等待，再依次为限位、居中、跟踪。状态跨时钟域通过握手传输，画面在帧起始更新，最多约一帧显示延迟。
显示采用组合字体叠加，不增加视频流水线延迟，不使用帧缓存。
本轮已增加按键消抖及恢复新样本验证；尚未进行本版本上板验证。

## 跟踪联动与目标关联（后续优化）

- 冻结、回放、A/B对比、差分等非实时帧模式强制暂停电机跟踪；切换模式或A/B源帧年龄也会锁存暂停。串口命令本身继续执行。
- 非实时模式下K2不能恢复跟踪；返回实时模式后，仍需松开并重新按K2恢复，避免自动启动。
- K1或串口T实际改变阈值时，自动清除控制器确认及目标关联，等待两次新的有效选择样本后继续。写入相同阈值不重置。手动暂停期间改阈值不会自动恢复。
- 首次搜索仍优先水平靠近中心的三角形。锁定后优先匹配上一位置及尺寸：水平和垂直中心差各不超过160像素，宽高分别在上一目标的1/2～2倍之间；代价为4倍水平位移加垂直位移及宽高变化。
- 连续三帧未匹配后解除关联，下一帧重新全画面搜索；恢复跟踪仍需两次有效样本确认。暂停、阈值重确认时清除旧关联。

位置和尺寸关联不能保证区分重叠且外形相近的目标；目标每帧移动过大或尺寸突变时，会暂时失配并重新搜索。本改动未增加图像缓存，尚需综合资源、时序及上板验证。

本轮功能回归通过：帧模式与K2联锁、阈值重新确认触发、位置/速度控制及超时、完整异步跟踪链路、多目标干扰与尺寸突变关联。测试脚本与构建产物仅留本地。
