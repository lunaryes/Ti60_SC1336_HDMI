## 1. 目标

**效果目标**（相对现有 `sobel_edge`）：

| 指标 | 现状 Sobel | Canny 目标 |
| --- | --- | --- |
| 边缘宽度 | 2~3 像素 | **1 像素**（NMS） |
| 单边重复响应 | 有 | 无（NMS 去重） |
| 噪声假边 | 多（一个坏点成一圈假边） | 少（高斯 + 双阈值） |
| 断边 | 阈值一高就断 | 少（滞后连接） |
| 定位精度 | 一般 | 高（落在梯度极值处） |

**范围**：

- 做：**硬件近似版 Canny**（3x3 高斯 → Sobel 梯度 → 4 扇区方向量化 → NMS → 单遍双阈值滞后），全部在 `clk_pixel` 单域、行内流式处理。
- 不做：整帧迭代式严格滞后（需帧缓冲 / DDR3 多遍扫描）；5x5 高斯（先 3x3，效果不够再评估）。

**定位**：U5 可选扩展项之一。Canny 自带高斯平滑（替代中值去噪）和滞后连接（替代形态学补边），因此**与"中值 + 形态学"是二选一关系**，不叠加使用。

## 2. 基线现状（可直接复用）

### 2.1 可复用的东西

| 复用对象 | 说明 |
| --- | --- |
| `pix_window_3x3` | 唯一例化，I-B 冻结。Canny 与 Sobel 一样**消费同一组 `p11..p33`**，不新增像素窗口 |
| `sobel.v` 的流水线骨架 | S1 加权和（系数 2 用位拼接移位，无 DSP）+ S2 有符号相减，可直接搬到 S2/S3 级 |
| 插入点 | 仍是 AWB 之后、`FrameBoundCrop` 之前，`example_top.v` 不动 |
| 时钟域 | 全部 `clk_pixel`（74.25 MHz）单域 |

### 2.2 资源基线（`ARCH.md` §4 实测，Efinity 2026.1 `efx_map`）

| 模块 | FF | LUT | RAM |
| --- | --- | --- | --- |
| `u_pix_window_3x3` | 128 | 149 | 6 × EFX_RAM10 |
| `u_image_pipeline`（整条） | 294 | 243 | 6 × EFX_RAM10 |

- 端口顺序、`vsync`/`de` 语义、延迟冻结要求见 `INTERFACE.md` §2，本方案不新增约定。

## 3. 算法方案（硬件近似版）

### 3.1 总体结构

```
p11..p33 ──► S1 高斯 3x3 ──► S2 加权和 ──► S3 Gx/Gy ──► S4 幅值+方向 ──┐
   (来自 pix_window_3x3)      （同 sobel S1）  （有符号11b）            │
                                                                      ▼
                                                    ┌── 梯度行缓存 ×2（同步读）
                                                    ▼
                              S5 NMS ◄── 3x3 梯度窗（mag + dir）
                                                    │
                                                    ▼
                              S6 双阈值 + 滞后（复用同一 3x3 窗）
                                                    │
                                                    ▼
                                            edge_o / mag_o
```

关键设计点：**NMS 和滞后判定复用同一个 3x3 梯度窗**，全流程只需要 2 个行缓存，不需要第三个窗口。

### 3.2 S1 高斯平滑（3x3）

核 `[1 2 1; 2 4 2; 1 2 1] / 16`，直接吃 `p11..p33`，`>>4` 用移位实现，无除法、无 DSP。

- 输出 `g22[7:0]`，宽度不增加。
- 高斯取代了中值滤波的去噪位置；若要两者并存，中值放在 Canny **之前**（可选，不在本方案范围）。

### 3.3 S2/S3 Sobel 梯度

与 `sobel.v` 的 S1/S2 完全同构：加权和（系数 2 用移位）→ 有符号相减。

- `Gx = (p13 + 2*p23 + p33) - (p11 + 2*p21 + p31)`（右列 − 左列）
- `Gy = (p31 + 2*p32 + p33) - (p11 + 2*p12 + p13)`（下行 − 上行）
- 范围 −1020 ~ +1020，`signed [10:0]`。

### 3.4 S4 幅值 + 方向量化

**幅值**：用精确的 `mag = |Gx| + |Gy|`（12 bit，0~2040），**不用** `max + min/2` 近似 —— 原因有二：

1. NMS 靠幅值比较定"谁是极大值"，近似会引入比较误差；
2. L1 在硬件上本来就只要一个加法器，比近似版**更省**（近似版要多一个比较器 + 两个 mux + 移位）。

**方向量化成 4 个扇区**（避免 `atan2` 和除法）：

| 判据 | 扇区 | NMS 比较的邻居 |
| --- | --- | --- |
| `\|Gy\| ≤ 0.414·\|Gx\|` | 0°（水平梯度） | `p21` / `p23` |
| `\|Gx\| ≤ 0.414·\|Gy\|` | 90°（垂直梯度） | `p12` / `p32` |
| 否则，`Gx` 与 `Gy` **同号** | 45°（梯度指向右下） | `p11` / `p33` |
| 否则，异号 | 135°（梯度指向右上） | `p13` / `p31` |

- `tan(22.5°) = 0.4142` 用 **106/256 = 0.41406** 近似（误差 0.04%），`106 = 64+32+8+2` → 4 次移位 + 3 次加法。
- 比较在整数域做：`(|Gy| << 8) ≤ 106·|Gx|`，约 19 bit 比较器，两个（0° 和 90° 各一个）。
- 符号只用于在两种对角情形间二选一，用 `Gx[10] == Gy[10]` 判断。
- 方向只参与"比较哪两个邻居"，不参与幅值，所以量化误差不影响幅值精度。

**方向编号 `dir[1:0]`**：`00`=0°、`01`=90°、`10`=45°、`11`=135°。

### 3.5 S5 梯度行缓存窗口

NMS 需要**梯度场**的 3x3 邻域（相邻行/列的幅值与方向），而 `pix_window_3x3` 提供的是灰度邻域，无法复用 → 需要新增 2 个梯度行缓存。

- 存储内容：`{mag[11:0], dir[1:0]}` = 14 bit/像素。
- 容量：2 × 1280 × 14 ≈ 35.8 kbit → 预计 4~8 块 `EFX_RAM10`（按 `pix_window` 实测折算：深度 1280 > 1024 需 2 块级联，宽度 14 > 10 需 2 块并联，每 bank 约 4 块）。
- **必须同步读**（见 §2.3）。
- 面积吃紧时的退化方案：缓存 `mag >> 3`（0~2040 → 0~255，单调、无饱和平台）+ `dir` = 10 bit，每 bank 2 块。代价是 NMS 比较精度下降到 1/8 量化步长。

### 3.6 S6 非极大值抑制（NMS）

```
nms_keep = (mag >= mag_左邻) && (mag >= mag_右邻)      // 邻居由 dir 选
```

- 用"平局保留"（`>=`）而不是严格大于：严格大于会把平坦边缘整段删掉，`>=` 最多留下 2 像素宽的平台。**待评审**（见 §11）。
- 抑制掉的像素 `mag` 置 0。

### 3.7 S7 双阈值 + 滞后（单遍近似）

```
strong = nms_keep && (mag8 >= thr_high_i)
weak   = nms_keep && (mag8 >= thr_low_i)
edge_o = strong || (weak && 8 邻域内存在 strong)
```

- **单遍近似**：只做一次 3x3 传播，不是真正的连通域递归。效果介于 Sobel 和 OpenCV Canny 之间，硬件上不需要帧缓冲。
- 邻域的 `strong` 用**未过 NMS 的原始幅值**判定（标准 FPGA 简化做法），这一点要在模块头注释里写明，避免后人误以为是严格 Canny。
- 更强的近似（流式反馈：把已处理的 `edge_o` 结果也纳入邻域判定）列为 M4 之后的候选，需要仔细处理扫描方向依赖。
- 滞后判定与 NMS 复用同一个 3x3 梯度窗，不额外增加行缓存。

### 3.8 阈值域（重要）

内部判据统一用 **`mag8 = mag >> 3`**（0~2040 → 0~255，单调无饱和）。接口上 `thr_high_i` / `thr_low_i` 都是 8 bit，语义就是这个域。

- 换算：`thr = 40` 对应真实 `|Gx|+|Gy| = 320`。
- **与 `sobel_edge` 的 `thr_i` 不可直接混用**（sobel 是先饱和到 255 再比）。文档和寄存器默认值都要写清。
- 显示输出 `mag_o` 建议用**饱和版** `min(mag, 255)`，与现有 sobel 的视觉亮度一致；内部判据用 `mag8`。两者用途不同，模块头注释要说明。

## 4. 接口设计（I-B，冻结候选）

```verilog
module canny_edge #(
    parameter LATENCY = 0        // 实现后填写并冻结
)(
    input  wire        clk,
    input  wire        rst_n,

    input  wire        vsync_i,
    input  wire        de_i,
    input  wire [7:0]  p11, p12, p13,
    input  wire [7:0]  p21, p22, p23,
    input  wire [7:0]  p31, p32, p33,
    input  wire [7:0]  thr_high_i,
    input  wire [7:0]  thr_low_i,

    output reg         vsync_o,
    output reg         de_o,
    output reg  [7:0]  mag_o,
    output reg         edge_o
);
```

- 端口顺序符合 `INTERFACE.md` §2（`clk, rst_n, vsync_i, de_i, <data_in>, <ctrl_in>, vsync_o, de_o, <data_out>`）。
- 文件：`src/image/canny_edge.v`，模块名 `canny_edge`。
- **与 `sobel_edge` 同插槽**：`image_pipeline_top` 里替换那一个实例即可，`sobel.v` 文件保留（做回归对照走分支/图样，不做同 bitstream 双实例）。
- 顶层选择方式：`image_pipeline_top` 增加参数（如 `EDGE_ALGO`）用 `generate` 二选一，默认 Canny；或直接替换实例。**待评审**（见 §11）。

## 5. 延迟预算

| 级 | 拍 |
| --- | --- |
| S1 高斯 | 1 |
| S2/S3 梯度 | 2 |
| S4 幅值 + 方向 | 1 |
| S5 梯度行缓存（写 1 + 同步读 1） | 2 |
| S6 NMS | 1 |
| S7 滞后 + 输出寄存 | 1 |
| **`canny_edge` 合计** | **8** |

对外总延迟：`rgb_to_gray 1 + pix_window 2 + canny 8 + image_mix 1 = 12` 拍（原为 8 拍）。

因此 `image_pipeline_top` 的 `ORIG_LAT` 要从 **7 改为 11**，`vsync/de` 对齐同步改。原图路径是纯寄存器延迟，成本可控，但**必须与延迟推导注释一起改**，改完做旁路回归（`mode 0` 逐像素一致）。

延迟值在 M1 完成后回填 `INTERFACE.md` 和 `ARCH.md` 并冻结。

## 7. 时序与流水划分

- 目标时钟 74.25 MHz（13.46 ns），每级组合深度控制在 **2 层 LUT + 一层比较/加法**以内。
- **反面教材**：本仓库 `feature_sobel_edge` 分支上的 `sobel_edge.v` 把整个 Sober 运算 + 对比度拉伸压进一拍，没有流水，时序余量被吃光。Canny 的组合链只会更长，**每一级都必须有寄存器**，`vsync/de` 逐级移位对齐（沿用 `sobel.v` 的做法）。
- 风险最高的两级是方向量化（移位加 + 19 bit 比较）和滞后（3x3 或树 + 双比较），必要时各拆成两级、LATENCY 相应增加。

## 8. 验证方案

1. **参考模型**：Python/MATLAB 实现同一套近似算法（4 扇区 + 单遍滞后），生成激励与期望输出，逐像素比对。注意参考模型必须用同样的近似，否则比对必然不一致。
2. **仿真用例**（新建 `sim/`，本分支此前没有）：

   | 用例 | 关注点 |
   | --- | --- |
   | 均匀场 | 不应产生任何边缘；高斯和 NMS 都不该引入假响应 |
   | 单像素坏点 | 高斯后应被削弱到阈值以下 |
   | 竖直/水平/斜 45°/斜 135° 直线 | NMS 后宽度必须是 1 像素，四个方向都要测 |
   | 1~2 像素细线 | 检查高斯是否把它抹平（这是 Canny 相对开关式中值的取舍点） |
   | 强弱边混合 | 滞后是否正确连接弱边、丢弃孤立弱响应 |
   | 首末行/末列 | 依赖 `pix_window_3x3` 的边缘复制，确认无异常 |
   | `de=0` 区段 | `mag_o`/`edge_o` 必须为 0，`vsync/de` 对齐正确 |

3. **板上验证**：静态图样 + 实景，与 sobel 对比"边缘连续性 / 假边 / 边缘宽度"，并确认旁路（mode 0）逐像素一致。

## 10. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 方向量化在扇区边界处造成边缘断裂 | 先测四个方向的直线；必要时对边界扇区做双方向比较（成本上升，放 M5 评估） |
| 单遍滞后残留断边，达不到预期 | 备选流式反馈版（§3.7）；或 Canny 后加一级形态学膨胀（复用 U5 的 `morphology_3x3`） |
| 行缓存推断不出 BRAM（异步读陷阱） | §2.3 铁律；综合后核对 RAM 报告，异常立即回查读地址是否寄存 |
| 时序不收敛 | §7 的分级拆分预案；LATENCY 变更要同步改顶层和文档 |
| 延迟从 8 变 12 影响顶层与文档 | M4 单独提交 + 旁路回归；同步更新 `INTERFACE.md` §5/§6、`ARCH.md` §2/§4 |
| 阈值域与 sobel 混淆导致调参错乱 | §3.8 明确写进模块头注释和接口文档 |

## 11. 待评审决策（Open Questions）

1. **是否用 `generate` 保留 sobel 与 canny 二选一**，还是直接替换实例？（资源 vs 对照便利性）
