# DDR 应用帧存储

2026-10-22：以 `ddr_video_store.v` 替换旧 `axi4_ctrl` 接线。原本已存在的相机到 DDR 通道，现在保存完整、可选择的原始帧，再读取送入 ISP/Canny。

## 数据路径与容量

SC1336 RAW8 → 异步写 FIFO → DDR 完整帧 → 帧选择 → DDR 读取 → ISP/灰度/中值→ 高斯/Sobel/NMS/连接/AA → HDMI。

- 每帧 1280×720×1 字节，921600 字节。每槽地址间隔 1 MiB，使用 DDR 前 16 MiB，共 16 槽。
- 写入槽无效；收到最后一个 AXI 写响应且像素计数正确后才发布为完整帧。最多保留 15 个完整帧；30 fps 时约半秒，属于短片段循环缓存。
- 保护当前显示、参考以及仍在读取的槽，避免读写同帧。显示帧切换时分时扫描元数据选择帧。
- 冻结、回放及对比模式在相机帧尾停止录入，保留缓存内容；恢复实时后继续循环录入。相机本身继续工作。
- FPGA 片内只保存短突发缓存及接口 FIFO，不再为串口图像诊断保存 ROI 或完整帧。

## 功能

| 模式 | 行为 |
| --- | --- |
| live | 显示最近完整帧，持续采集 |
| freeze | 停止录入，显示指定历史年龄的帧 |
| replay | 停止录入，在保留帧中按旧到新循环播放 |
| compare | 停止录入，左半画面来自 A、右半来自 B；各取原坐标，未缩放成两幅完整图 |
| difference | 停止录入，显示 RAW8 的绝对差×4并饱和到255，随后仍经过 ISP；不是灰度亮度差 |

年龄0为最近完整帧，1为前一源帧。指定年龄不存在时选择最接近的保留帧。回放间隔按 HDMI 显示帧计数，默认2；源帧率与显示帧率不一定相同。

## 当前处理链路

时域 IIR 已从当前工程移除。中值滤波后直接进入 Canny；DDR 只承担 RAW 帧存储、选帧和读取。IIR 源文件和旧测试保留作历史参考，不在工程清单中。

## 使用

Windows 安装了 pyserial 的 Python：

```powershell
python sim/video_control.py --port COM6 --mode live
python sim/video_control.py --port COM6 --mode freeze --age 0
python sim/video_control.py --port COM6 --mode replay --replay-div 2
python sim/video_control.py --port COM6 --mode compare --age 0 --reference 1
python sim/video_control.py --port COM6 --mode difference --age 0 --reference 1
python sim/video_control.py --port COM6 --mode live
```

脚本先检查固件协议标识，再设置参数并输出状态；不会下载固件或保存诊断图像。`--layout original|edge|split|overlay` 分别选择原图、算法支路、左灰度右边缘、左灰度右原图叠加亮黄色边缘（默认）。`overlay` 对应 HEX `4D 03`，`52` 回读 `layout=3`；此布局强制使用边缘掩码，其他布局由 `--view gray|edge` 控制算法视图。图形标注用 HEX `45 00` / `45 01` 关闭/开启。

## 二进制串口协议

460800 baud、8N1。设置命令为 ASCII 命令码接一个原始数值字节，不是十进制字符串。

| 命令 | 参数/回复 |
| --- | --- |
| P | 0实时、1冻结、2回放、3左右帧对比、4绝对差 |
| N | 旧命令，消耗一个参数字节但不执行 |
| J / K | A / B 的历史年龄，低4位，默认0/1 |
| O | 回放每帧持续的显示帧数，1…255；0钳制为1 |
| F | bit0：冻结1/实时0快捷方式 |
| Q | 8字节：`56 mode 00 ageA ageB divider 00 0A` |
| D | 8字节：`44 56 01 status[7:0] status[15:8] status[23:16] status[31:24] 0A` |
| R | 保持原有8字节图像设置回读 |

D 的 status：低16位为显示源 A 序号；18:16为生效模式；23:19为扫描时保留完整帧数；31:24为粘滞错误。错误bit0：不完整采集帧，bit1：AXI写响应错误，bit2：AXI读响应错误。状态通过请求/应答邮箱原子跨时钟域读取。源序号16位会回绕。

T/S/M/A/B 保持原有含义；L 已退出。Q 已改为应用配置回读，不再回复旧抗锯齿标识。顶层只保留 V=0边缘、V=3灰度；V=1/2按边缘处理。H 直方图与旧图像诊断链不接入综合，旧诊断脚本不能用于此固件。旧源码和离线测试可作为历史参考，不占板上资源。

## 验证范围

`bash sim/run_video_store.sh`：行为 FIFO/DDR 模型，带 AXI 背压和延迟写响应，检查冻结不被覆盖、历史选择、回放、对比、差分及逐输出字节的混合结果。模型不能替代真实 DDR/FIFO 时序验证。

`bash sim/run.sh`：原有 Canny、流水线、灰度、UART、按键和中值回归；直方图测试仅验证历史模块，应用顶层不例化它。上板后的视觉效果、显示连续性和运动拖影须独立验证。
