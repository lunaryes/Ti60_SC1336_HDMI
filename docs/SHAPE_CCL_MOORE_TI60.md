# VF-Ti60F225：CCL + Moore 图形识别支路

## 参考与实现边界

参考 MIT ObNoDog 项目的「连通区域分离 → 外轮廓跟踪 → 几何特征分类 → 屏幕标注」结构：

- 报告：https://fpga.mit.edu/videos/2024/team01/report.pdf
- 原项目：https://github.com/jca0/ObNoDog-final

这里是针对 Ti60 的独立 RTL 实现，不是直接移植原项目的 Xilinx IP 或源码。CCL 解决“哪些像素属于同一目标”，Moore 解决“这个目标的外轮廓怎样走”；二者本身不等于字符 OCR，也不能保证任意背景的准确识别。

## 与本板实际工程的对应

- FPGA：Ti60F225，C4 时序模型，Verilog-2005。
- 输入：SC1336 摄像头已有 RGB/灰度/Canny 流，1280×720。
- 全部新逻辑使用既有 `clk_pixel`、`rstn_pixel`。约 74.4 MHz，以工程约束 13.4409 ns 为准；不增加时钟域或 PLL。
- 不改 DDR3 控制器、摄像头配置、HDMI、引脚及外围 XML。
- 保留 KEY1 三档平滑、KEY2 阈值循环调节及原 UART 协议。
- 保留数字/大写英文字母 V3 识别支路和原橙色 OCR 搜索框。几何支路扫描全画面，不受橙框限制；它不是数字识别精度升级的替代品。

## 数据流

```
现有 Canny 二值输出 ──────────────→ 原画面合成/HDMI（不增流水线延时）
           │ 只读抽头
           └→ 8×8 OR 池化（160×90）
              → 3×3 闭运算（连接细小断口）
              → 八连通 CCL（队列洪泛，visited 标记）
              → 每个连通域的 Moore 外轮廓跟踪
              → 外轮廓面积、周长、包围框、RDP 顶点与转角
              → 形状分类 → 连续两次确认 → 消隐期更新 → 框和英文标签
```

CCL 用队列洪泛完成八连通标记，而不是 MIT 的两遍等价标签表；两者都属于连通组件标记。Moore 使用有向起始边重复的结束判据，避免仅回到起点或特定回溯方向造成提前结束/死循环。面积由闭合外轮廓鞋带公式计算，空心三角形不会因为“白色像素占比低”而直接被当作无目标。

RDP 简化后删除闭合曲线分段产生的近共线伪顶点。分类同时检查凸性、直角、边长、圆形度等，不只依赖单一圆形度。实现包含三角形、正方形、矩形、圆、椭圆、五边形、六边形、轴对齐十字及其它凸四边形；不满足条件时不显示类别。

## 文件

- `shape_sdp_ram.v`：同步读写存储器，允许推断 EBR，不复位整个数组。
- `shape_frame_capture.v`：完整帧捕获及 OR 池化；引擎忙时跳过分析帧，不阻塞视频。
- `shape_geometry_engine.v`：闭运算、CCL、Moore、RDP 和分类状态机。
- `shape_geometry_top.v`：接入及两帧确认、结果原子更新。
- `shape_geometry_overlay.v`：青色框、绿色英文标签；标注区以外像素直通。
- `image_pipeline_top.v`：仅增加 Canny 二值/DE/VS 只读输出。

## 上板测试方法

1. 先用纯色卡或白纸测试单个高对比图形，移除浏览器边框、文字水印和其它图案。
2. 正对摄像头，保持图形完整位于画面内，主体宽高建议不小于约 256 像素；先保持静止至少半秒。
3. 先测空心/实心正方形，再测正立/倒立三角形、圆和矩形；最后测多个分离图形。
4. 确认右侧 Canny 可见完整边缘，再观察青色几何框和绿色英文标签。
5. 边缘缺失时用 KEY2 调低阈值或 KEY1 减弱平滑；噪声增多时反向调节。已有 `O` 命令 `4F 00` / `4F 01` 同时关闭/开启两类标注，便于比较原有边缘画面。
6. 分别记录“边缘是否完整、连通域是否粘连、框是否正确、类别是否正确”，不要将显示有轮廓直接当作识别成功。

## 已知限制

- 8×8 池化与闭运算会合并距离太近的目标；间距至少约 24 像素。小圆与多边形可能混淆，需要足够尺寸。
- 当前保留按扫描顺序遇到的前四个有效形状，不是置信度排序的任意数量检测器。
- 摄像头斜拍会把矩形变为四边形、圆变为椭圆；此版不做透视校正。
- 多图形交叠、粘连、破损轮廓、复杂背景和 UI 外框可能影响 CCL。全画面扫描不等于任意场景检测。
- 每目标最多 4096 个轮廓点，每次分析有 2,000,000 时钟看门狗；超限拒识，不拖停 HDMI。
- 同一槽位连续两次类别和框位置接近才显示；目标变化后会清除旧标签，因此运动中可短暂消失。
- 存储器位数预算约 35 万 bit（捕获/临时/工作/visited、队列和轮廓），实际 EBR/DSP/LUT 数量和时序应以 Efinity 报告为准。
- 仿真图案通过不等于实际摄像头精度已经验证；需要按照以上步骤上板验证。
