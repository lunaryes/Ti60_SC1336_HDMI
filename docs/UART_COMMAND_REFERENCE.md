# VF-Ti60F225 Canny 串口命令参考

本文档对应当前工作树的实现，代码来源：

- `Ti60F225_SC1336_HDMI_Display/src/common/uart_cmd.v`
- `Ti60F225_SC1336_HDMI_Display/src/control/canny_threshold_key_ctrl.v`
- `Ti60F225_SC1336_HDMI_Display/example_top.v`

> 本协议是二进制字节协议，不是文本命令行。除单字节命令 `R`、`Q`、`H` 外，所有命令都是
> “1 字节命令码 + 1 字节原始参数”。

## 1. 串口设置与接线

| 项目 | 设置 |
| --- | --- |
| 波特率 | **460800 bit/s**（74.25 MHz 分频 161，误差 -0.08%） |
| 数据位 | 8 |
| 校验位 | None |
| 停止位 | 1 |
| 流控 | None |
| 电平 | **1.8 V LVCMOS** |
| FPGA 接收 | `uart_rx_i`，`GPIOT_N_16` |
| FPGA 发送 | `uart_tx_o`，`GPIOT_P_16` |

USB-UART 与开发板交叉连接：

```text
USB-UART TX  -> FPGA uart_rx_i
USB-UART RX  <- FPGA uart_tx_o
USB-UART GND -- FPGA GND
```

开发板接口配置为 1.8 V。不要把不支持 1.8 V 的 3.3 V/5 V 串口模块直接接入；
应使用支持 1.8 V 的 USB-UART 或电平转换器。

## 2. 协议规则

### 2.1 参数命令

参数命令固定为两个字节：

```text
[命令码，1 byte] [参数，1 byte]
```

例如设置 Canny 强阈值为 12：

```text
54 0C
```

其中 `54` 是 ASCII 字符 `T` 的十六进制编码，`0C` 是数值 12 的原始字节。

不要发送文本 `T 12`。它实际对应：

```text
54 20 31 32
```

解析器会把紧跟 `T` 的空格 `20` 当作参数，使阈值变成 32，而字符 `1`、`2`
会被忽略。

### 2.2 查询命令

查询命令只有一个字节：

```text
52
```

即 ASCII 字符 `R`。FPGA 随后返回 8 个二进制字节。

### 2.2.1 固定 AA 状态回读

发送单字节 `51`（ASCII `Q`），返回 `41 41 01 02 T S L 0A` 共8字节。
`41 41` 是签名，`01` 为版本，`02` 是固定 AA 标识；T/S 为实际阈值与平滑，L 为连接开关。
灰度抗锯齿上电即启用，无需发送 E02。E00/E01/E02 均已移除，E 为未知命令，不等待参数。
M 仍选择原图、边缘或分屏布局；V 仍选择 AA 边缘、幅值、状态色或灰度视图。

### 2.3 解析器特性

- 参数命令没有校验和、结束符或自动应答，应在写入后发送 `52` 查询确认。
- 解析器收到参数命令后会一直等待下一个字节，没有超时退出机制。
- 等待参数期间，新收到的 `T/V/M/A/B/S/L` 会被当作前一条命令的参数。
- 在命令位置收到未知字节、回车 `0D`、换行 `0A` 或空格 `20` 时会直接忽略。
- 查询回包发送期间再次发送 `R`，新查询可能被丢弃。8 字节回包在 460800 bit/s
  下约需 0.17 ms，建议两次查询至少间隔 5 ms。

## 4. 各命令说明

### 4.1 `T`：设置 Canny 阈值

格式：

```text
54 <thr_high>
```

- `thr_high = 参数字节`
- `thr_low = thr_high >> 1`
- 当前推荐工作点为 `thr_high=12`、`thr_low=6`。
- 阈值越低，弱边缘越多，同时更容易出现噪声；阈值越高，边缘更少、更干净。
- 串口可以写入完整的 8 位范围；板上 K2 的循环范围是 4～48，步长 1。

示例：

| 目的 | 发送字节 |
| --- | --- |
| 阈值 5 | `54 05` |
| 阈值 8 | `54 08` |
| 阈值 12（推荐） | `54 0C` |
| 阈值 16 | `54 10` |
| 阈值 24 | `54 18` |

串口写入和按键作用于同一个生效阈值寄存器。在同一时钟发生冲突时，串口写入优先。
K2 每按一次增加 1；达到 48 后再按一次回到 4（回绕）。串口写入 4..48 内的值时，
K2 从该值继续 +1；写入 0..3 或 49..255 时，下一次按 K2 先回到 4。

### 4.2 `V`：设置边缘支路视图

格式：

```text
56 <view>
```

| 参数 | 视图 | 用途 |
| --- | --- | --- |
| `00` | 灰度抗锯齿边缘图 | 黑底白线，观察最终边缘 |
| `01` | `mag8` 梯度灰度图 | 判断梯度强弱、辅助选择阈值 |
| `02` | 六状态假彩图 | 区分无梯度、NMS 抑制、弱边及强边，并单列"仅因传播保留" |
| `03` | Y 灰度图 | 查看算法实际使用的灰度输入（中值后） |

六状态图颜色：

| 颜色 | 含义 |
| --- | --- |
| 黑 | 无梯度或低于弱阈值 |
| 深红 | 有梯度，但被非极大值抑制 NMS 淘汰 |
| 黄 | 弱边，但单遍滞后没有把它连上 |
| 蓝 | 弱边，并被单遍滞后保留 |
| **绿** | 弱边，单遍滞回没有连上，但被**方向约束流式反馈**沿切向传播保留（`L=01` 时才可能出现） |
| 白 | 强边 |

发送 `4C 00` 关闭边缘连接后，绿色应全部消失（这些像素回到黄色），其余像素
逐像素不变；`4C 01` 恢复默认。这是判断"新逻辑到底连了什么"最直接的方法。

`V` 只改变边缘支路的内容。如果 `M=00` 显示原图，改变 `V` 不会在屏幕上体现。

### 4.3 `M`：设置最终显示模式

格式：

```text
4D <mode>
```

| 参数 | 显示模式 |
| --- | --- |
| `00` | 全屏原图 |
| `01` | 全屏边缘支路，具体内容由 `V` 决定 |
| `02` | 左半**灰度图**、右半边缘支路 |
| `03` | 当前暂时等同 `02`（画中画未实现） |

上电默认 `mode=03`，即左右分屏。左半显示的是中值后的算法灰度 `{Y,Y,Y}`；
分屏接缝处左半比右半高约 3 行（灰度与边缘支路在流水线中的取点深度不同），
属已知现象。

### 4.4 `A`、`B`：设置 AWB 通道增益

格式：

```text
41 <gain_r>
42 <gain_b>
```

换算公式：

```text
实际增益 = 参数字节 / 64
参数字节 = round(实际增益 × 64)
```

| 实际增益 | 十进制参数 | 十六进制参数 |
| --- | ---: | --- |
| ×0 | 0 | `00` |
| ×1.0 | 64 | `40` |
| ×1.5 | 96 | `60` |
| ×1.75 | 112 | `70` |
| ×2.0 | 128 | `80` |
| ×2.5 | 160 | `A0` |
| ×3.0 | 192 | `C0` |

当前默认值：

- R 通道：112，即 ×1.75；
- B 通道：96，即 ×1.50。

### 4.5 `S`：设置高斯平滑模式

格式：

```text
53 <smooth_mode>
```

| 参数 | 模式 | 效果 |
| --- | --- | --- |
| `00` | S0 标准高斯 | 抗噪最好，细小齿轮和链条边缘可能被削弱 |
| `01` | S1 弱平滑 | 细节与抗噪的折中，当前默认和推荐模式 |
| `02` | S2 完全旁路 | 细节最多，也最容易检测到噪声和屏幕纹理 |

串口 `S` 和 K1 作用于同一个生效模式寄存器。在同一时钟发生冲突时，串口写入优先。
K1 的循环顺序为：

```text
S0 -> S1 -> S2 -> S0 -> ...
```

当前上电默认是 S1，因此上电后第一次按 K1 会切换到 S2。平滑模式由 `canny_edge`
在帧同步上升沿锁存，切换不会在画面中间出现接缝。

### 4.6 `L`：设置边缘连接开关

格式：

```text
4C <link_en>
```

- `link_en = 参数 bit0`：`01` 打开方向约束流式反馈（复位默认），`00` 关闭。
- 关闭后 `edge` 回到"强边 + 单遍滞后"的旧行为，`view=2` 里的绿色全部消失，
  用来在**同一块板、同一幅画面**上对比开/关，不用重新综合。
- 开关在 `vsync` 上升沿锁存，切换不会撕裂当前帧。
- 该功能只改变弱边的保留判决，**不改变流水线延迟**（仍为 12 拍）。

示例：

| 目的 | 发送字节 |
| --- | --- |
| 打开边缘连接（默认） | `4C 01` |
| 关闭边缘连接（对比旧行为） | `4C 00` |

### 4.7 `R`：查询当前状态

发送：

```text
52
```

返回固定 8 字节：

| 字节序号 | 字段 | 含义 |
| ---: | --- | --- |
| 0 | `thr` | 当前实际生效的 Canny 强阈值，包括 K2 修改结果 |
| 1 | `view` | 当前边缘支路视图 |
| 2 | `mode` | 当前最终显示模式 |
| 3 | `gain_r` | 当前 R 通道增益参数 |
| 4 | `gain_b` | 当前 B 通道增益参数 |
| 5 | `smooth` | 当前实际生效的平滑模式，包括 K1 修改结果 |
| 6 | `link` | 当前边缘连接开关（`00` 关 / `01` 开） |
| 7 | `0A` | 回包结束标记（换行） |

当前版本复位后的典型回包：

```text
0C 00 03 70 60 01 01 0A
```

解释：阈值 12、灰度抗锯齿边缘视图、左右分屏、R 增益 ×1.75、B 增益 ×1.5、弱平滑 S1、
边缘连接开。

## 5. 推荐调试流程

### 5.1 恢复常用显示状态

依次发送：

```text
54 0C    # 阈值 12
56 00    # 灰度抗锯齿边缘视图
4D 01    # 全屏边缘
53 01    # 弱平滑
41 70    # R 增益 ×1.75
42 60    # B 增益 ×1.50
4C 01    # 打开边缘连接
52       # 查询确认
```

期望回包：

```text
0C 00 01 70 60 01 01 0A
```

### 5.2 排查边缘在哪一步消失

1. 发送 `4D 01`，确保显示边缘支路。
2. 发送 `56 03` 看 Y 灰度图，确认输入灰度正常。
3. 发送 `56 01` 看梯度图，确认目标位置存在梯度。
4. 发送 `56 02` 看六状态图，判断是 NMS 淘汰、弱边未连接还是阈值过高。
5. 若看到黄色断口：发送 `4C 01`/`4C 00` 对比，绿色就是方向约束反馈
   新连接上的弱边；若绿色也不出现，说明断口两侧方向不相容或中间确实没有弱响应。
6. 使用 `54 xx` 扫描阈值；也可以直接按 K2/串口微调。
7. 使用 `53 00/01/02` 比较标准高斯、弱平滑和旁路。
8. 每次修改后发送 `52`，保存参数回包和屏幕照片。

## 6. Python/pyserial 示例

```python
import serial

ser = serial.Serial("COM7", 460800, bytesize=8,
                    parity="N", stopbits=1, timeout=0.2)

def set_param(command: str, value: int) -> None:
    ser.write(bytes((ord(command), value & 0xFF)))

def read_status() -> dict:
    ser.reset_input_buffer()
    ser.write(b"R")
    data = ser.read(8)
    if len(data) != 8 or data[7] != 0x0A:
        raise RuntimeError(f"invalid reply: {data.hex(' ')}")
    return {
        "threshold": data[0],
        "view": data[1],
        "mode": data[2],
        "gain_r": data[3] / 64.0,
        "gain_b": data[4] / 64.0,
        "smooth": data[5],
        "link": data[6],
    }

set_param("T", 12)
set_param("V", 0)
set_param("M", 1)
set_param("S", 1)
print(read_status())
```

将 `COM7` 改成设备管理器中实际显示的串口号。不要使用 `ser.write(b"T 12")`，
因为那是文本而不是本协议要求的原始字节。
