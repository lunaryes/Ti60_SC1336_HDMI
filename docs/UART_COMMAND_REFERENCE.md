# VF-Ti60F225 串口命令参考（DDR 帧存储 / 灰度递归 IIR 版）

本文对应当前 `uart_cmd.v`、`ddr_video_store.v` 和 `example_top.v`。所有发送示例均为 **HEX 原始字节**。串口助手选择 **HEX 发送 / HEX 显示**，关闭自动追加回车换行；复制字节序列即可，不发送命令名称或说明文字。

## 1. 串口设置

| 项目 | 设置 |
| --- | --- |
| 波特率 | 460800 bit/s |
| 数据格式 | 8 数据位、无校验、1 停止位（8N1） |
| 流控 | 无 |
| 当前连接 | COM6，以设备管理器实际端口为准 |
| 接线 | USB-UART TX → FPGA uart_rx_i；RX ← FPGA uart_tx_o；GND 共地 |
| 电平 | 1.8 V LVCMOS，需匹配电平的串口模块或转换器 |
| 引脚 | 接收 GPIOT_N_16；发送 GPIOT_P_16 |

## 2. 协议规则

- 设置命令：1 字节命令码 + 1 字节参数，不自动回复。
- 查询命令：单独发送 `52`、`51` 或 `44`，各返回固定 8 字节。
- 下表中的字节、参数范围、回复示例均为十六进制；说明中的帧数、阈值等自然数另行注明。
- 设置后用 `52` 查询图像设置，用 `51` 查询帧存储配置，用 `44` 查询生效状态。
- 参数命令没有超时；只发送命令码后，下一个字节一定会作为参数，包括其他命令码。请完整发送两个字节。
- 不在回复期间叠加查询：每次读满 8 字节再发下一条，查询之间建议间隔至少 5 ms。切换帧模式后建议等待 100 ms 再查询生效状态。
- 参数及回复可能含有 `0A`，接收应按固定长度读取，不能遇到 `0A` 就提前结束。

例如设置阈值为十进制 12，发送：

```text
54 0C
```

| DDR 帧模式 | `50` | `00` 实时；`01` 冻结；`02` 回放；`03` 两帧左右对比；`04` 差分 | `50 01` |
| 灰度 IIR 降噪开关 | `4E` | bit0：`00` 关，`01` 开 | `4E 01` |
| A 帧历史年龄 | `4A` | 低4位，`00`～`0F`；`00` 为最近完整帧 | `4A 03` |
| B 帧历史年龄 | `4B` | 低4位，`00`～`0F`；用于对比/差分参考 | `4B 01` |
| 回放间隔 | `4F` | `01`～`FF` 个显示帧；`00`钳制为`01` | 每帧显示4次：`4F 04` |
| 冻结快捷控制 | `46` | bit0：`01` 冻结，`00` 返回实时 | `46 01` |
| 查询图像设置 | `52` | 无参数，返回8字节 | `52` |
| 查询帧存储配置 | `51` | 无参数，返回8字节 | `51` |
| 查询帧存储状态 | `44` | 无参数，返回8字节 | `44` |

## 4. DDR 模式与操作示例

DDR 使用16个槽，最多保留15个完整的1280×720 RAW8帧。以30 fps采集约对应半秒。冻结、回放、对比和差分模式会在相机帧边界停止录入，保留缓存；返回实时后继续循环采集。

### 4.1 实时显示与降噪

| 操作 | 发送字节 |
| --- | --- |
| 返回实时 | `50 00` |
| 开启运动自适应灰度 IIR 降噪 | `4E 01` |
| 关闭灰度 IIR 降噪，比较效果 | `4E 00` |
| 查询配置 | `51` |
| 查询生效状态 | `44` |

降噪现为中值后的灰度递归 IIR，默认当前帧权重自适应为1/2、3/4或1（可调）。重复源帧直接复用已滤波结果；首次帧或历史跳转时初始化。对比和差分模式不使用 IIR。

### 4.2 冻结与历史帧选择

| 操作 | 发送字节 |
| --- | --- |
| 选择最近帧并冻结 | `4A 00 50 01` |
| 冻结快捷命令 | `46 01` |
| 冻结后查看前3个源帧的画面 | `4A 03` |
| 重新选择最近帧 | `4A 00` |
| 恢复实时快捷命令 | `46 00` |

年龄按源帧计算，不是按显示刷新次数。指定年龄没有保留时选择最接近的完整帧。实时模式总是选择最近完整帧，A 年龄设置用于冻结和帧对比等模式。

### 4.3 短片段循环回放

每个源帧显示2个显示周期，然后按旧到新循环回放：

```text
4F 02 50 02
```

减慢至每个源帧显示4个显示周期：

```text
4F 04
```

回放速度由显示帧率及间隔决定；并非按采集时间戳恢复原速。回放模式由内部游标选择 A 帧，不使用手动设置的 A 年龄。

### 4.4 两帧左右对比

选择 A 为最近帧，B 为前一源帧，进入左右对比，并选择全屏原图布局：

```text
4A 00 4B 01 50 03 4D 00
```

左半来自 A，右半来自 B，各取原图对应坐标；不是把两幅完整图缩放后并排显示。

若要对比各半画面的边缘结果，可继续发送：

```text
56 00 4D 01
```

DDR 帧对比与最终显示布局是两个独立设置。最终布局为 `02`/`03` 时会再按左灰度、右算法支路显示，观察两帧原图对比宜使用 `4D 00`。

### 4.5 两帧差分

选择最近帧与前一帧，显示绝对差：

```text
4A 00 4B 01 50 04 4D 00
```

输出为 RAW8 同坐标绝对差×4并饱和至255，之后经过原有 ISP，不是最终灰度图的直接差分。

## 5. 回复格式

### 5.1 图像设置查询：发送 `52`

| 字节位置（从0开始） | 含义 |
| --- | --- |
| 0 | 实际 Canny 强阈值，包含按键修改 |
| 1 | 视图寄存器；`01`/`02` 在当前顶层仍按边缘显示 |
| 2 | 最终显示布局 |
| 3 | 红通道增益参数 |
| 4 | 蓝通道增益参数 |
| 5 | 实际空间平滑模式，包含按键修改 |
| 6 | 边缘连接开关 |
| 7 | 固定 `0A` |

当前工程复位默认回复：

```text
0C 00 03 70 60 01 00 0A
```

对应阈值12、边缘视图、左右分屏、红增益×1.75、蓝增益×1.5、弱平滑、边缘连接关闭。

### 5.2 帧存储配置查询：发送 `51`

| 字节位置（从0开始） | 含义 |
| --- | --- |
| 0 | 固定标识 `56` |
| 1 | 请求的 DDR 帧模式，`00`～`04` |
| 2 | 灰度 IIR 降噪开关，`00`/`01` |
| 3 | A 帧年龄，`00`～`0F` |
| 4 | B 帧年龄，`00`～`0F` |
| 5 | 回放间隔，`01`～`FF` |
| 6 | 保留，固定 `00` |
| 7 | 固定 `0A` |

复位默认回复：

```text
56 00 01 00 01 02 00 0A
```

配置回读表示请求值，实际帧切换是否完成应查看 `44` 回复。

### 5.3 帧存储状态查询：发送 `44`

| 字节位置（从0开始） | 含义 |
| --- | --- |
| 0 | 固定 `44` |
| 1 | 固定 `56` |
| 2 | 协议版本 `01` |
| 3 | 状态字 bit7:0 |
| 4 | 状态字 bit15:8 |
| 5 | 状态字 bit23:16 |
| 6 | 状态字 bit31:24 |
| 7 | 固定 `0A` |

状态字为32位小端整数：

| 状态位 | 含义 |
| --- | --- |
| bit15:0 | 显示源 A 帧序号，16位回绕 |
| bit18:16 | 生效的 DDR 帧模式 |
| bit23:19 | 扫描时保留的完整帧数 |
| bit31:24 | 粘滞错误标志，正常为 `00` |

错误字节：bit0为不完整采集帧，bit1为 AXI 写响应错误，bit2为 AXI 读响应错误。标志复位后清除，模式切换不清除。

示例回复：

```text
44 56 01 57 04 79 00 0A
```

其中 A 帧序号为 `0457`（十进制1111）；状态字节 `79` 的低3位为 `01`（冻结），高5位为 `0F`（15个完整帧）；错误字节为 `00`。

## 6. 常用图像设置

| 操作 | 发送字节 |
| --- | --- |
| 阈值5 / 8 / 12 / 16 / 24 | `54 05` / `54 08` / `54 0C` / `54 10` / `54 18` |
| 边缘视图 | `56 00` |
| 中值后的算法灰度视图 | `56 03` |
| 全屏原图 | `4D 00` |
| 全屏算法支路 | `4D 01` |
| 左灰度、右算法支路 | `4D 02` |
| 标准高斯 / 弱平滑 / 旁路 | `53 00` / `53 01` / `53 02` |
| 打开 / 关闭边缘连接 | `4C 01` / `4C 00` |
| 红增益×1.75 / 蓝增益×1.5 | `41 70` / `42 60` |

布局 `03` 当前等同 `02`。边缘连接复位默认关闭；抗锯齿固定开启。K1循环空间平滑模式，K2循环阈值4～48，串口与按键同时写入时串口优先。

恢复常用实时左右分屏状态（最后一字节查询图像设置）：

```text
50 00 4E 01 4A 00 4B 01 4F 02 54 0C 56 00 4D 02 53 01 41 70 42 60 4C 00 52
```

图像设置期望回复：

```text
0C 00 02 70 60 01 00 0A
```

## 7. Python：使用十六进制整数发送

命令使用 `bytes` 和十六进制整数构造，不使用字符串命令或字符编码转换。

```python
import time
import serial

with serial.Serial(port="COM6", baudrate=460800, timeout=0.5) as ser:
    ser.reset_input_buffer()
    # 实时、降噪开启、最近帧、参考前一帧。
    ser.write(bytes([0x50, 0x00, 0x4E, 0x01, 0x4A, 0x00, 0x4B, 0x01]))
    time.sleep(0.1)

    # 查询帧存储配置，固定读取8字节。
    ser.write(bytes([0x51]))
    config = ser.read(8)
    if len(config) != 8 or config[0] != 0x56 or config[7] != 0x0A:
        raise RuntimeError("配置回复无效")
    print(config.hex(" "))

    # 查询实际状态，小端解码。
    time.sleep(0.005)
    ser.write(bytes([0x44]))
    reply = ser.read(8)
    if len(reply) != 8 or reply[:3] != bytes([0x44, 0x56, 0x01]) or reply[7] != 0x0A:
        raise RuntimeError("状态回复无效")
    status = int.from_bytes(reply[3:7], byteorder="little")
    print("源帧序号:", status & 0xFFFF)
    print("生效模式:", (status >> 16) & 0x07)
    print("完整帧数:", (status >> 19) & 0x1F)
    print("错误标志:", (status >> 24) & 0xFF)
```

## 8. 灰度递归 IIR 状态与融合计数

原有 `4E 01` 现在开启灰度 IIR，`4E 00` 关闭。当前算法不再叠加旧 RAW FIR。

| 操作 | 发送字节 | 回复格式（8字节） |
| --- | --- | --- |
| 查询 IIR 历史状态，并快照三组计数 | `49` | `49 49 01` + 4字节状态小端 + `0A` |
| 查询高置信融合像素数（默认当前权重1/2） | `55` | `55 49 01` + 4字节计数小端 + `0A` |
| 查询不确定区融合像素数（默认当前权重3/4） | `57` | `57 49 01` + 4字节计数小端 + `0A` |
| 查询旁路/初始化像素数（当前权重1） | `58` | `58 49 01` + 4字节计数小端 + `0A` |

依次单独发送 `49`、`55`、`57`、`58`，每次收满8字节后再发下一条。三组计数由 `49` 在同一时刻锁存；重复缓存显示不覆盖最后一次计算的计数。正常完整帧三者合计921600（十六进制 `000E1000`）。计数仅证明算法参与程度，不代表边缘闪动改善比例。

IIR状态字：bit0为本轮历史异常；bit2:1为操作（`00`旁路、`01`初始化、`02`递归、`03`缓存复用）；bit3为历史有效；bit23:8为已提交的历史源帧编号；bit31:24为粘滞错误（bit0：像素欠载/帧计数异常；bit1：读响应或突发长度错误；bit2：写响应错误）。其他位保留。

`44` 的高错误字节现为 RAW 存储与 IIR 历史错误的按位合并；需要区分原因时读取 `49`。实时处理时历史提交编号可能比正在显示的源编号滞后一帧，完成写入后才更新是正常行为。

## 9. 抗残影 IIR 运行时调参（新固件，尚未烧录）

设置命令仍为两个HEX字节，不使用文本命令。参数在下一个帧配置边界锁存；变化后重新初始化历史，包括冻结的同一源帧，避免继续使用旧参数的滤波结果。建议修改后等待100 ms，再观察效果。

| 操作 | HEX发送 | 说明 |
| --- | --- | --- |
| 选择参数索引 | `59 00` | 示例选择索引 `00`，合法范围 `00`～`07` |
| 写入当前选中参数 | `5A 02` | 示例将值写为 `02` |
| 查询当前选中参数 | `5B` | 回复8字节，格式见下文 |
| 恢复全部8项默认参数 | `5D` | 单字节，不改变当前选中索引 |

参数表中的默认字节为HEX；门限说明中的灰度级为十进制。

| 索引 | 参数 | 默认字节 | 默认含义 |
| --- | --- | --- | --- |
| `00` | 高置信区域当前帧权重编码 | `01` | 当前1/2，历史1/2 |
| `01` | 不确定区域当前帧权重编码 | `02` | 当前3/4，历史1/4 |
| `02` | 高置信残差上限 | `02` | 2级灰度 |
| `03` | 不确定区域残差上限 | `05` | 5级灰度 |
| `04` | 高置信水平/垂直变化上限 | `04` | 4级灰度 |
| `05` | 不确定区域水平/垂直变化上限 | `08` | 8级灰度 |
| `06` | 允许融合的绝对帧差上限 | `18` | 24级灰度 |
| `07` | 局部亮度补偿的绝对上限 | `08` | 正负8级灰度 |

索引 `00`、`01` 的权重编码：`00`=当前1/4，`01`=当前1/2，`02`=当前3/4，`03`=当前1。权重写入超过 `03` 时钳制为 `03`，不会回绕到强滤波。索引 `02`～`07` 允许 `00`～`FF`；高置信门限应不大于对应的不确定区门限。越小越容易判为运动并采用当前画面。

索引超出 `07` 时忽略写入；查询返回值 `FF`、错误标志 `01`。

查询回复格式：

```text
5B 49 02 <索引> <参数值> 00 <错误标志> 0A
```

例如查询默认绝对差上限：

```text
59 06 5B
```

预期回复：

```text
5B 49 02 06 18 00 00 0A
```

### 9.1 默认抗残影参数

恢复本版默认并启用 IIR：

```text
5D 4E 01
```

### 9.2 仍有残影时，进一步减弱历史

高置信区域改为当前3/4，不确定区域改为直接当前帧：

```text
59 00 5A 02 59 01 5A 03
```

或者只将允许融合的绝对差上限从24改为16：

```text
59 06 5A 10
```

局部亮度补偿上限从8改为4，减少把物体变化当成照明变化的可能：

```text
59 07 5A 04
```

以上调节会减少历史依赖，也可能增加静止边缘闪动。每次只改变一组，先观察运动停止后的旧轮廓，再观察静止细字。

### 9.3 多项修改与回读

可以先关闭IIR，修改多项，最后开启：

```text
4E 00 59 00 5A 02 59 01 5A 03 59 06 5A 10 4E 01
```

查询选中的参数只返回配置值；历史重建是否完成用 `49` 查看。像素计数 `55`、`57` 对应两种判定类别，实际权重由索引 `00`、`01` 决定；若某类设置为纯当前，该类像素归入 `58` 旁路计数。

Python控制脚本也支持调参（不会下载固件）：

```powershell
python sim/video_control.py --port COM6 --iir-tuning
python sim/video_control.py --port COM6 --iir-param 0x00 0x02 --iir-param 0x01 0x03
python sim/video_control.py --port COM6 --iir-defaults
```

该接口需加载抗残影调参版固件。旧版灰度IIR没有 `59`～`5D` 接口；当前任务仅生成离线位流，不执行烧录，也未在实物上验证残影改善。

## 10. 已退出的诊断命令



- `48`：当前顶层未接入直方图，不回复，不应再等待旧778字节数据流。
- `45`：旧抗锯齿切换命令已移除；抗锯齿固定开启。
- `51`：已改为应用配置回读，不再回复旧抗锯齿标识。
- `56 01`、`56 02`：当前顶层按边缘显示，不再提供梯度图或状态假彩图。
- 旧 ROI、冻结图像串口回传脚本不适用于当前应用固件。

帧存储结构、算法和验证范围见 [DDR_VIDEO_STORE.md](DDR_VIDEO_STORE.md)。
