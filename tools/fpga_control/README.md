# Ti60 串口上位机

适用于本工程当前固件（无 IIR、无 link）。独立桌面程序，不需要浏览器，也不修改 FPGA 位流。

## 启动

本机已具备 Python 3.14、Tk 和 pyserial，双击同目录 `启动上位机.cmd`。
也可运行：

```powershell
python tools/fpga_control/app.py
```

其他电脑需安装带 Tk 的 Python 3 和依赖：

```powershell
python -m pip install -r tools/fpga_control/requirements.txt
```

串口固定 460800、8N1，无流控。先关闭占用 COM6 的其他串口软件，再选择端口并连接。
连接只查询，不自动更改 FPGA 参数。关闭程序会释放串口。

## 操作

- 显示与边缘：选择布局、视图、平滑、阈值和红蓝增益，再点“应用图像设置”。增益数值除以64为实际倍率。
- 图形标注：通过应用图像设置发送；协议没有标注开关回读，复选框仅代表准备发送/最近发送的值。
- DDR帧缓存：A/B年龄、回放保持帧数与模式按钮。模式按钮会先发送当前A/B和间隔，再切模式。
- 对比/差分按钮同时发送 M=0，便于全屏观察DDR结果；不会自动关闭图形标注，如需干净画面可先取消标注再应用。
- 恢复黄色叠加：切实时，再选择左灰度/右原图黄色边缘，点击应用图像设置。
- “读取并同步参数”将回读参数填入编辑框；每秒自动刷新仅更新状态，不覆盖尚未发送的编辑值。
- HEX发送只允许当前支持的完整指令；在发送前验证全部字节，拒绝不完整参数帧和已移除的IIR/link指令。支持 Q/R/D 查询并按固定8字节读取，参数中出现0A不会被当作结束。
- 通信记录可以保存为文本。超时后关闭自动刷新，检查连接、供电及串口占用，再重连。

状态中的源帧编号会回绕；错误为固件粘滞标志，重新连接上位机不会清除硬件错误。
本工具没有图像预览或帧导出功能，因为当前固件没有图像回传接口。
传感器曝光来自I2C LUT，当前协议无法通过此上位机修改曝光。

## 验证与连接排查

可先检查 Python 文件语法：

```powershell
python -m py_compile tools/fpga_control/app.py tools/fpga_control/protocol.py
```

本目录仅交付运行所需文件，未附带本地协议测试脚本。
如端口列表为空，先检查 USB 串口连接和 Windows 设备管理器；若端口存在但无法打开，检查是否被其他程序占用；能够打开但查询超时，再检查板卡供电、匹配固件、波特率及 RX/TX/GND 接线。COM6 仅为界面默认值，应选择实际枚举的端口。

当前默认标准高斯、阈值12，阈值范围4～32。三角形跟踪版板上K1循环加4（32后回4），K2消抖后单击切换暂停/恢复跟踪；平滑仅由串口/上位机修改。固件与上位机需配套更新。

三角形跟踪版：非实时帧模式及切换源帧会自动暂停跟踪，返回实时后需按K2恢复；阈值改变会触发目标重新确认。串口命令仍正常执行。

当前 Gamma 0.70 为 FPGA 显示分支的编译期配置，上位机不提供 Gamma 或传感器曝光的在线调节。

## 电机暂停与恢复

上电及复位后默认暂停跟踪，需按 K2 或点击“恢复跟踪”后才开始跟踪。电机跟踪区提供“暂停跟踪”和“恢复跟踪”按钮，并读取 FPGA 实际状态。串口和 K2 共用一个使能寄存器，重复发送暂停或恢复不会反复翻转。

- 暂停为保持当前 PWM 位置命令，不关闭 PWM，也不切断执行器供电。
- 恢复仍需新的目标样本确认；冻结、回放、对比、差分等历史帧模式强制暂停，不能通过串口绕过。
- 回到实时模式后，需按“恢复跟踪”或 K2；修改阈值继续沿用重新确认机制。
- 状态读取后与 K2 同步；勾选每秒刷新可持续观察，未勾选时以最近一次回读为准。
- 旧固件仍能连接并使用原功能，但电机按钮禁用，需重新生成并烧录支持此协议的位流。

新增二进制命令：`55 00`（U 00）暂停，`55 01`（U 01）恢复；其他参数忽略。`43`（C）查询，回复 `43 54 01 flags status 00 00 0A`，其中 flags 的 bit0为手动使能、bit1为阈值重确认期间、bit2为历史帧联锁；status低4位沿用跟踪 usable/centered/invalid/limit 定义。查询只返回数字控制状态，不代表机械位置反馈。

Q回复保留8字节，在第7字节（索引6）使用 `A1` 标记支持电机协议。上位机先探测此标记，只向支持的固件发送 C/U，旧固件不会因新增查询而超时。固件未更新时，单独更新 Python 程序不能控制电机。
